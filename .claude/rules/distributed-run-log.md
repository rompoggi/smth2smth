# Distributed run log (mandatory)

**Applies to every agent session on this repo.** Same rules as `.cursor/rules/distributed-run-log.mdc`.

## Problem

Several hosts update the repo; shared `report/track_a.tex` / `report/track_b.tex` logbooks cause Git merge conflicts.

## Solution

Each **(username, hostname)** pair maintains **one** markdown log. No cross-editing.

## Resolve your file

```bash
RUN_LOG_USER="$(whoami)"
RUN_LOG_HOST="$(hostname | cut -d. -f1)"
RUN_LOG_FILE="report/${RUN_LOG_USER}/${RUN_LOG_HOST}.md"
```

- User: output of `whoami` (e.g. `romain.poggi`, `thomas.turkieh`).
- Host: `hostname` with domain stripped at the **first dot** (`rouget.polytechnique.fr` → `rouget`).

## Permissions

| Allowed | Forbidden |
|---------|-----------|
| Create/edit **only** `report/$(whoami)/$(host).md` | Any `report/{other_user}/**` or `report/{you}/{other_host}.md` |
| Link `experiments/*.md` (read-only) | Edit **`experiments/**`** when only logging a run |
| — | `report/track_a.tex`, `report/track_b.tex` **unless the user explicitly asks** |

## When to write

Log on experiment **start**, **finish**, **failure**, **stop**, or **submission** (when the user is running training/eval work):

1. Compute `RUN_LOG_FILE`.
2. Insert a **new** section at the top (after the file header), preceded by `---`.
3. Update the **top** section only if it is the same run still `RUNNING`.

## Section template

```markdown
---

## {Descriptive title} | Track {A|B|A+B} | {YYYY-MM-DD HH:MM}

- **Status:** RUNNING | DONE | FAILED | STOPPED
- **Run:** {name}
- **Experiment:** [`{doc}`](../../experiments/{doc}.md) — **experiments/** spec; **no line numbers**
- **Hydra:** `experiment={preset}` (text only, not a link to `configs/experiment/`)
- **Log:** [`…`](../../logs/track_a/…) — per **start-resume-runs** layout
- **W&B:** [run](url) if training; omit for submit
- **PID:** link only if RUNNING + pid file exists
- **Ckpt:** `{path}`
- **Metrics:** {concise results only}
- **Submit:** `{csv}` → LB **{pct}** (optional)
```

- **Track** label: `A`, `B`, or `A+B`.
- **Timestamp:** `date '+%Y-%m-%d %H:%M'` when writing.
- **Content:** experiment **outcomes and status** only — no code walkthrough, no long hyperparameter lists.

## New file header

```markdown
# Run log — {user} @ {host}

Machine-local experiment log. Other hosts/users have their own files under `report/{user}/{host}.md`. Do not edit this file from another account or machine.

```

## Experiment references (`experiments/` — read-only when logging)

- Link the spec in **`experiments/`**: [`doc`](../../experiments/doc.md) from `report/{user}/{host}.md`.
- Never use line-number references into those markdown files.
- Do **not** edit `experiments/**` when appending a log entry.
- Hydra preset: plain `` `experiment=foo` `` — do not link `configs/experiment/foo.yaml` from the run log.

## LaTeX (`track_a.tex`, `track_b.tex`)

Modify **`report/track_a.tex` or `report/track_b.tex` only if the user explicitly asks**. Otherwise markdown logs are the source of truth for distributed runs.

Launch/resume procedure: **`start-resume-runs.md`** in this folder.
