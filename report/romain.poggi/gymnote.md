## Training data and validation protocol (Track A stab runs)

These runs use the standard **official-val holdout** setup in `train.py` when `dataset.official_val_holdout_ratio=0.1` (see [`diver_CL_head_continue`](../../experiments/diver_CL_head_continue.md)).

| Split | Clips | In training? | Used for |
|-------|------:|--------------|----------|
| `data/train` | 44,993 | yes | train |
| **90% of `data/val`** (stratified, `dataset.seed`) | 6,069 | **yes** | train + logged as **honest val** |
| **10% holdout** (same stratified split) | 676 | **no** | **best checkpoint, early stopping** |
| **Honest val** (= all 6,745 official val clips) | 6,745 | 90% overlap with train | monitoring only |

**Checkpoint selection is not leaky:** `Saved new best checkpoint` uses **holdout top-1 only** (`holdout_stats` / `ema_holdout_stats` in `src/smth2smth/pipelines/train.py`). Honest val is logged each epoch but does not drive `best_top1`.

**Why honest val looks ~7–10 pp higher than holdout:** ~90% of honest-val clips were also in the training set (memorization / familiarity). Example at ep21 on this run: holdout **57.25%**, clips-from-val-in-train **64.13%**, honest **63.44%** (= weighted mix). Do **not** use honest val for model selection or LB expectations.

**Holdout split:** `split_train_val_stratified(..., val_ratio=0.1, seed=int(cfg.dataset.seed))` — for `arch2-perceiver-q16-stab-s42`, **`seed=123`** (not 42). Holdout **N = 676**.

Log line (typical):

```text
[data] train=51062 (train_dir=44993 + val_dir=6069 (90% stratified)), val_holdout=676 / val_total=6745
[data] dual val eval each epoch: holdout n=676 (checkpoint/early-stop), honest n=6745 (full official val; includes clips also used in training)
```

## Bug: Perceiver head skipped in ViT submit TTA path (fixed 2026-05-25)

**Symptom:** First champion submit **~4% LB** despite **~57% holdout** at ep21; predictions collapsed (e.g. class 31 ≈23% of rows).

**Cause:** `smth2smth.pipelines.submit._videomae_logits_batch` (and `ensemble/inference.py` copy) pooled encoder tokens with **`mean(dim=1)`** when `attn_pool` was absent, instead of **`pool_head`** (Perceiver). Training and holdout eval use `VideoMAEViT.forward()` → `pool_head`; submit did not.

**Fix:** `elif getattr(model, "pool_head", None) is not None: pooled = model.pool_head(features)` in `submit.py` and `ensemble/inference.py`. Regression test: `tests/pipelines/test_submit_tta.py::TestVideomaePerceiverSubmitPath`.

**Do not upload** CSVs generated before this fix (no `_v2` suffix).
